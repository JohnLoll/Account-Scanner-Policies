Privacy Policy

AccountScanner · Last updated: October 20, 2026

AccountScanner is a Discord bot that helps server staff spot possible alternate (alt) Roblox accounts. This page explains what it collects and how that data is used. By using the bot, you agree to this policy.

What we collect

  • Public Roblox data: things like username, display name, user ID, account creation date, badges, inventory, groups, friends, and other information Roblox makes publicly available.
  • Discord data: your Discord user ID and username, server IDs, and any settings or notes saved through the bot's commands.
  • Detection results: scores, flags, and matches the bot generates by comparing accounts.

The bot does not collect private information such as passwords, emails, or login cookies, and it does not read your messages.

How it's used

The data is used only to run the bot's alt detection and to let moderators review results. It is not sold or used for advertising.

Who can see it

Results are visible to staff of the servers using the bot. Data may also be handled by Discord, Roblox's public API, and our hosting provider as needed to run the bot, or shared if required by law.

How long we keep it

Public Roblox data and detection results are kept for as long as they are useful for running the bot.

Age requirements

Like Discord, you must meet Discord's minimum age to use the bot. We don't knowingly collect data from anyone under that age, and Roblox's own age rules apply to Roblox accounts.

Changes

We may update this policy at any time. Continuing to use the bot means you accept the changes.

Contact

Questions or want something removed? Join our support server and open a ticket or message a staff member.
